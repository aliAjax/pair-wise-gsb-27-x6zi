# 物流报价复核台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

可追溯的物流报价复核台，数据保存在浏览器 localStorage（键：`hxwlfront-13-review`），刷新后报价、冲突拦截记录与协议修订链均保留。

## 核心规则

- **计价**：录入起止城市、重量、体积、服务时效后，按体积重（1m³ = 167kg，抛比 1:6000）与实际重量取大得到计费重，落入对应计价档（≤30 / 31-100 / 101-300 / 301-1000 / >1000kg，各时效单价与最低消费不同），再叠加报价日生效中的客户协议折扣。
- **协议冲突**：同一客户同一线路的生效中协议生效期不得重叠；保存时若重叠则阻止保存，列出每段冲突区间并记入冲突拦截记录。
- **冻结与修订**：报价确认后费用明细冻结；调整协议只生成新修订（旧版本标记为已取代，修订链完整保留），历史报价绝不重算，仅草稿可按当前协议重新计价。
