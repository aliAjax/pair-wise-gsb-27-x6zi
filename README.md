# 物流报价复核台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

可追溯的物流报价复核工具，数据保存在浏览器 localStorage，刷新后报价、冲突提示与修订链均保留。

## 核心规则

- **计价**：体积重 = 体积(m³) × 200kg/m³，与实际重量取大得到计费重量，按服务时效（标准达/次日达/冷链）匹配计价档（基础费 + 续重单价），再叠加当天生效的客户协议折扣。
- **协议冲突**：同一客户同一线路的协议生效期不得重叠；保存时校验，冲突则阻止保存并列出冲突区间（持久化保留，可逐条知悉）。
- **冻结与修订**：报价确认后费用明细冻结，不可修改、不可重算、不可删除；协议不可删改，调整只生成 v+1 新修订，旧版本标记"已被修订"，修订链完整可查；草稿报价在确认前可按当前协议重新试算。
